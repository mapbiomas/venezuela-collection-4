## 1. Introduction and Rationale

Once training samples are generated, supervised classification relates reference class labels to Landsat spectral bands and indices to assign a land cover class to every pixel in the region.

The script [`03-0-classifier.js`](../03-0-classifier.js) automates this workflow across all 41 years from 1985 to 2025. For each year, it loads the mosaic, locates the sample asset, applies optional class remaps, optionally excludes or resamples classes in specific polygons, trains a Random Forest classifier, and appends each annual band into a single multiband image (`classification_1985` through `classification_2025`).

### 1.1 What Problem Does It Solve?

- Applies a supervised classifier consistently across the entire 1985–2025 series.
- Automatically consumes annual sample assets identified by region, year, and version.
- Validates mosaic variables, sample availability, and class diversity (> 1 class) before training.
- Supports targeted class adjustments both in training samples and in classified outputs via polygon remaps.
- Allows replacing samples inside problematic polygons with complementary points sampled directly from the mosaic.
- Produces a consistent multiband image ready for downstream post-classification filtering.

> [!CAUTION]
> **Critical check:** `remap_to_21` (and any other item included in `remap.polygons`) must be defined before `remap.polygons` is constructed, or the script will fail before processing starts.

### 3.2 Classification Region

The region is retrieved via `functions.getRegion()` from:

```text
projects/mapbiomas-venezuela/assets/DATOS-AUXILIARES/VECTORES/ve-gu-regiones-clasificacion
```

It queries `gridcode` (`regions_field`) using `region_id = 90222` in the default script, using `region.vector` for geometry operations and `region.rasterMask` to mask mosaics and outputs.

### 3.3 Mosaics

Venezuela and Guyana mosaics are loaded via `functions.getMapBiomasMosaics()` requesting the 34 bands in `feature_space`, merged, and filtered to `season = "full"`. For regions in `andean_region_ids` (`92001`–`92009`), Venezuelan mosaics additionally apply `andean_filter` (retaining `ANDES` scenes and non-Andean scenes intersecting the region).

### 3.4 Training Samples

Samples are read from:

```text
projects/<user>/assets/MAPBIOMAS-VENEZUELA/LANDSAT/COLLECTION4/GENERAL/SAMPLES/<region_id>-<year>-<samples_version>
```

At startup, the script lists assets in `samples_path` using `ee.data.listAssets(samples_path).assets` to verify availability before loading each year.

> [!NOTE]
> **`listAssets()` pagination:** `ee.data.listAssets()` returns an asset array and may paginate via `nextPageToken`. The script uses only the first page response; if `SAMPLES` grows very large, verify that all expected assets appear in `processed_samples`.

## 4. Core Concepts

### 4.1 Supervised Classification and Random Forest

The script trains an `ee.Classifier.smileRandomForest` model using `samples` with `"reference"` as the class property and `bands` as input predictors (`numberOfTrees = 100`, `variablesPerSplit = 1`).

```javascript
var classifier = ee.Classifier.smileRandomForest({
  numberOfTrees: trees,
  variablesPerSplit: 1,
});
```

> [!NOTE]
> `trees = 100` and `variablesPerSplit = 1` are explicit methodological settings for this version. Any change should be logged and benchmarked against reference runs.

### 4.2 Feature Space

`feature_space` contains 34 predictor variables (6 median spectral bands, SMA fractions, spectral indices, and Tasseled Cap components). The script checks via `contained` that the annual mosaic contains all 34 bands before allowing training.

### 4.3 NoData = 27

When training validation fails for a year, `apply_classification()` appends a constant band of value `27`. Throughout the loop, the accumulated image applies `.unmask(27).updateMask(raster_mask).toByte()`, and is cast to `Int8` before export.

### 4.4 Class Remapping

The script supports remapping in two separate stages:
1. Remapping the `"reference"` property of training samples prior to training (`FeatureCollection.remap()`).
2. Remapping classified output pixels inside specific polygons (`functions.remapWithPolygons()`).

## 7. Annual Classification Methodology

### 7.1 Annual Mosaic Selection

For each year, the script filters `mosaics` by `year`, creates `year_mosaic`, and checks `bands` and `contained`:

```javascript
var bands = year_mosaic.bandNames();
var contained = bands.containsAll(ee.List(feature_space));
```

> [!WARNING]
> **Missing mosaic detection:** The script wraps `year_mosaic` with `ee.Algorithms.If(year_collection.size().gt(0), ..., null)` and checks `if (year_mosaic === null)` client-side. Because `ee.Image(...)` always returns a non-null server-side proxy object, that client check will not catch empty collections. Verify mosaic coverage for all target years before production runs.

### 7.2 Sample Loading and Remapping

The expected sample asset is `<region_id>-<year>-<samples_version>`. If absent from `processed_samples`, the year is skipped with a Console log. Otherwise, `FeatureCollection.remap(remap.samples.from, remap.samples.to, "reference")` remaps labels (`5 → 6` in the default config) and `ee.Filter.notNull(bands)` removes features with null values in any mosaic band.

### 7.3 Optional Class Exclusion (`remove_samples`)

`remove_samples` filters out training samples whose `reference` matches any excluded class ID. Note that an empty array `[]` is truthy in JavaScript, so `.filter(ee.Filter.inList("reference", []).not())` still runs and retains all samples.

### 7.4 Complementary Sampling and Spatial Replacement

When `additional_samples.polygons.length > 0`, `apply_resampling()` excludes original samples falling inside those polygons, draws new points from `year_mosaic` via `resample_cover()` (`seed: 1`, `scale: 30`, `EPSG:4326`), and merges both sets:

```javascript
samples = samples.filterBounds(outside_vector).merge(new_samples);
```

> [!IMPORTANT]
> - This mechanism **replaces** original samples inside `additional_samples.polygons` rather than simply adding points on top of them.
> - Every polygon must carry a valid `id` property for `reduceToImage(["id"], ee.Reducer.first())`.

### 7.5 Pre-Training Validation Rules

`apply_classification()` multiplies three numeric checks (`should_train = check_bands * check_samples * check_classes`):

| Check | Condition | On failure |
| :--- | :--- | :--- |
| Bands | `condition_class_id` (`contained`) | Skips training; sets annual band = `27` |
| Samples | `samples.size().gt(0)` | Skips training; sets annual band = `27` |
| Classes | `ee.Number(n_class_sample).gt(1)` | Skips training; sets annual band = `27` |

```javascript
var should_train = ee
  .Number(check_bands)
  .multiply(check_samples)
  .multiply(check_classes);
```

### 7.6 Training, Classification, and Band Accumulation

When `should_train` equals `1`, `classifier.train(samples, "reference", bands)` trains the Random Forest and classifies `mosaic.classify(...)`, renaming the band to `classification_<year>`. When `should_train` equals `0`, a constant `27` band is appended. After the loop finishes, `classified.slice(1)` removes the initial `0` seed band.

### 7.7 Post-Classification Spatial Remaps

If `remap.polygons` is non-empty, `apply_remaps()` passes the newly added annual band through `functions.remapWithPolygons()` (`remap_to_21` in the default configuration).

## 9. Visualization and Inspection

Only years listed in `preview` (`[1990, 1995, 2018, 2020]`) are added to the map:

| Layer | Contents | QA purpose |
| :--- | :--- | :--- |
| `MOSAICO <year>` | False-color `SWIR1–NIR–Red` yearly mosaic. | Check residual clouds, data gaps, and spatial continuity. |
| `CLASIFICACIÓN <year>` | `classification_<year>` band styled with `classification9`. | Inspect spatial patterns, borders, improbable classes, and remaps. |
| `SAMPLES <year>` | Remapped (and optionally resampled) training points. | Verify spatial distribution and spectral alignment. |

### Recommended Inspection Order

1. Turn on `MOSAICO <year>` to assess base imagery quality.
2. Turn on `SAMPLES <year>` to verify coverage across land cover classes.
3. Turn on `CLASIFICACIÓN <year>` to spot obvious misclassifications or salt-and-pepper noise.
4. Compare consecutive or key years and specifically inspect areas targeted by `remap_to_21`.

## 10. Execution Procedure

1. Open [`03-0-classifier.js`](../03-0-classifier.js) in the Code Editor and verify `user`.
2. Set `region_id` and confirm the region exists in `gridcode`.
3. Verify `samples_version` and ensure `SAMPLES` contains `<region_id>-<year>-<samples_version>` for all required years.
4. Review `remap.samples` and `remap.polygons` (`remap_to_21`).
5. Review `remove_samples` (leave `[]` if no classes are excluded).
6. If using complementary samples, ensure polygons have an `id` property and `polygons`, `classes`, and `points` match in length and order.
7. Confirm all 34 `feature_space` bands exist in both mosaics and sample assets.
8. Check `trees = 100`, `tile_scale = 8`, and `output_version`.
9. Click **Run** and check **Console** for missing-sample messages or errors.
10. Inspect `preview` map layers.
11. Inspect `RESULTADO` in Console (41 bands, metadata, and no unexpected all-`27` bands).
12. Start the `Export.image.toAsset` task in **Tasks** only after visual and logical checks pass.
13. Open the exported asset to confirm the full multiband series is intact.

## 11. Product Interpretation and Usage

- **Annual bands:** Each `classification_<year>` band stores the Random Forest prediction after configured spatial remaps.
- **Value `27`:** Represents unclassified / NoData pixels; do not treat it as a thematic land cover class and review it before running gap-filling (`03-2-gapfill.js`).
- **Next stage:** The exported multiband asset serves as direct input to gap-filling ([`03-2-gapfill.js`](../03-2-gapfill.js)) and subsequent spatial/temporal filters.

## 14. Troubleshooting

| Symptom | Likely cause / recommended action |
| :--- | :--- |
| `remap_to_21 is not defined` | Polygon/rule was not defined or imported; define it or remove it from `remap.polygons`. |
| `"No hay muestras disponibles para <year>"` | Expected asset is missing or omitted by `listAssets()`; check path, `samples_version`, and permissions. |
| Missing-mosaic year throws error instead of log | Client-side `year_mosaic === null` does not evaluate server-side objects; verify mosaic availability beforehand. |
| Entire annual band equals `27` | Validation check failed (`contained`, `samples.size() > 0`, or `n_class_sample > 1`). |
| Samples dropped by `filter(notNull)` | One or more mosaic band properties are null in the sample asset for that year. |
| Class `5` absent from training | `remap.samples` remaps `5 → 6` in the default configuration. |
| `additional_samples` has no effect | `additional_samples.polygons` is empty. |
| Error in `apply_resampling` (`reduceToImage`) | Polygons in `additional_samples.polygons` lack the `id` property. |
| Missing samples in `processed_samples` | `ee.data.listAssets()` may paginate; check if `SAMPLES` exceeds one page. |

## 15. Best Practices

- Complete end-to-end QA on one test region before running regional batches.
- Keep `samples_version` and `output_version` synchronized in a methodological changelog.
- Temporarily expand `preview` when auditing a new region or version.
- Keep `polygons`, `classes`, and `points` aligned in length and order in `additional_samples`.
- Check the share of `27` pixels per band before advancing to post-classification filtering.
